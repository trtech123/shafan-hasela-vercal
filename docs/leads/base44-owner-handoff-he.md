# מסירה למנהלת דף Base44 — לידים של יום גיבוש

עמוד `https://www.shafan-hasela.com/he/team-building-day/` מטמיע את `https://vegan-climb-the-summit.base44.app/`. בדף Base44 יש שני מופעים של אותו טופס: בראש העמוד ובתחתיתו. יש לחבר **את שניהם** לאותו מסלול שליחה. לא לשלוח פנייה אמיתית לצורך בדיקה ללא תיאום.

## מה לשנות ב־Base44

1. בדקי קודם את פעולת השליחה הקיימת בשני המופעים: האם היא רק פותחת WhatsApp, והאם קיימת כבר שמירה ל־Base44 או שליחה ליעד אחר. דווחי לנו על כל שמירה קיימת כדי למנוע כפילות.
2. בעת לחיצה מפורשת על שליחה, בצעי ולידציה לשם ולטלפון, ושילחי את הפרטים אל **פונקציית שרת של Base44**. השדות בטופס הנוכחי הם שם, טלפון, נושא והודעה אופציונלית; אין בו אימייל. יש לייצר `submissionId` מסוג UUID פעם אחת לכל פנייה ולהשתמש באותו מזהה גם בניסיון חוזר. יש להפעיל הגנת ספאם בצד השרת.
3. פונקציית השרת תשלח POST ב־JSON אל `landing-lead-webhook` של Supabase. היא תעביר `formId: "nurit-team-building"`, את `submissionId`, `submittedAt` בתקן ISO, `pageUrl: "https://vegan-climb-the-summit.base44.app/"`, את `fields.name`, `fields.phone`, את `topic` ואת `inquiry` אם נמסרה. אפשר לצרף `fields.email`, קמפיין ו־UTM רק אם נאספו בפועל. כתובת ה־endpoint המדויקת תימסר בערוץ תפעולי בעת ההפעלה.
4. האימות מתבצע **בשרת בלבד**: צרי גוף JSON מדויק (`rawBody`), זמן Unix בשניות (`timestamp`), וכותרות `X-Landing-Timestamp: <timestamp>` ו־`X-Landing-Signature: sha256=<hex HMAC-SHA256(secret, timestamp + "." + rawBody)>`. הסוד יוגדר רק ב־Base44 server secrets וב־Supabase Edge secrets. אין להכניס אותו לקוד הדפדפן, ל־HTML, לכתובת URL או ללוגים. כל ניסיון חוזר ישתמש באותו `submissionId`, עם חתימה מחושבת מחדש לפי גוף הבקשה והזמן הנוכחי.
5. רק לאחר תשובת `2xx` עם `accepted: true` הציגי הצלחה. אפשר אז לפתוח את הודעת ה־WhatsApp הקיימת, ולהוסיף בסופה בשורה נפרדת את `whatsappReference` שהתקבל בתשובה. במקרה של שגיאה אל תפתחי WhatsApp ואל תציגי כאילו הפנייה נשמרה; הציגי אפשרות ניסיון חוזר עם אותו מזהה. חסמי לחיצות חוזרות בזמן השליחה.

שמרי על אותה התנהגות בשני מופעי הטופס. אין צורך להכניס מפתח Supabase לדפדפן, ואין צורך לשנות את טופס WordPress: עמוד הקמפיין מציג כרגע iframe של Base44.

## בדיקת קצה מתואמת אחת, אחרי חיבור ואישור הפעלה

נשלח פנייה סינתטית אחת מאחד הטפסים, ונבדוק שנוצרה **רשומת `leads` אחת בלבד** עם שם, טלפון, נושא, מקור „דף נחיתה — יום גיבוש”, כתובת הדף וסטטוס „פתוח”. ננסה שוב עם אותו `submissionId` ונוודא שמספר הרשומות נשאר אחת. אם נשלחת גם הודעת WhatsApp, נוודא שהעברת הבוט מפנה לאותה רשומה. לפני הבדיקה יש לוודא שהמספר שבקישור WhatsApp מחובר לבוט הרלוונטי. בדיקה זו לא בוצעה עדיין.

## Provider invoice question

The [official Payper integration guide](https://docs.pelecard.com/documentation/payper-integration/) documents automatic invoice generation for hosted iframe/redirect payments when Payper parameters are included, and for payment links. It describes `CreatePayperInvoice` as a separate on-demand API. The [Create Payper Invoice reference](https://docs.pelecard.com/documentation/create-payper-invoice-api/) likewise describes an explicit call using `trxRecordId` and `Uid` for a card-linked Invoice-Receipt. Neither page establishes that a cloud `DebitRegularType` J4 request to CT20 automatically creates a Payper document, or a documented read-only API to retrieve such a document. Pelecard's statement may describe a merchant-specific CT20 setting, so no physical invoice request is sent by this application. An existing provider-issued document can instead be matched through the deployed admin manual reconciliation path after accountant confirmation of its number, URL, amount, transaction, and absence of a prior document.
